# 验知有道 v0.2

以电阻分压为首个实验的本地可运行教学试用版。学生与教师通过同一个后端读写 SQLite 数据库，界面沿用清爽蓝白设计。原有 PDF、实验规格和界面原型均保留在上级目录。

内网服务器入口：<http://10.31.26.22:8766/>。服务配置、日志、重启与数据位置见 [部署维护说明](deploy/README.md)。下面的启动步骤用于本机运行。

界面使用已确认的 v0.2 设计：学生单列实验对话、提取卡片与底部导航；教师窄侧栏、行内统计、AI 课堂摘要与进展图表。原型保存在 `design/approved-ui-v0.2.html`，样式保存在 `static/approved-ui.css`。原型示例数据不用于线上实验记录。

第一阶段提供课程与学期、实验内容库与不可变版本、教学班和名单、班级邀请码、学生注册、单人及多人分组、教师调整与自动分配、实验发布和跨任务独立的实验空间。课程管理入口沿用同一套组件样式。

## 第一阶段使用路径

教师登录后进入“我的课程”，创建课程并开设学期课程，在“班级与分组”建立教学班。可以添加已注册学生账号，也可以将班级邀请码提供给学生自行加入。名单可粘贴为每行一个账号，或每行“账号 姓名”。教师账号目前由维护人员配置，学生可在登录页注册。

在“实验内容”创建或复制实验，填写目标、步骤、材料和报告要求。分压实验可设置电阻参数、供电范围与容许偏差；其他实验可先使用通用观察记录方式。编辑内容会新建版本，已发布任务继续使用原版本。

点击“发布实验”，选择教学班和时间，设置人数范围，或者复用某个班已有的分组方案。先预览，再确认发布。学生在“我的课程”查看任务，可以独立完成、创建小组或加入同伴小组；教师也可为未分组学生自动分配。

开始记录实验后，小组成员锁定。教师调整成员需填写原因，原记录保留作者及当时的成员名单。同一小组针对不同任务拥有不同实验空间，修订和报告互不覆盖。教师可在教学总览按实验任务和班级查看进展。

复制到新学期保留教学班名称与课程结构，新学期重新安排学生和实验发布。归档后保留历史，恢复开课后可继续管理。

## 启动

双击本目录中的 `启动助教.command`，或在仓库根目录执行：

```sh
cd app
python3 run.py
```

打开 <http://127.0.0.1:8765>。默认只监听本机，也可通过 `LAB_HOST`、`LAB_PORT` 指定监听地址；停止后数据仍保存在 `data/`。重新启动即可继续查看。本机已具备依赖，换一台电脑时建议使用 Python 3.9 或更高版本创建独立环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run.py
```

## 已实现的流程

1. 学生输入自然语言，服务器提取供电、输出、单位和参考点，生成未确认草稿。可修正后确认；观察和提问单独保存。
2. 确认后保存原话、初始提取、人工修正、换算值和确定性判定。图表随真实记录更新，教师端每 6 秒刷新已保存数据。
3. 教师查看小组原始记录、曲线、求助和结论，起草指导并确认发送。学生端读取保存成功的教师消息。
4. 断电改线或换件建立新实物修订，旧数据保留。新修订不沿用旧测量，需要重新测量供电与输出。
5. 照片上传、学生结论提交、教师反馈或退回补充。提交固定关联证据，待审核和已反馈状态锁定学生编辑。
6. 基于当前权限范围的助教建议。未配置模型或调用失败时，明确显示实验规则建议；不会伪装成模型回答。
7. 离线或后端失联时可暂存输入文字，恢复后载入、重新提取并确认；不自动认定为已测量。写操作使用操作编号防止重试重复入库。

## 首条体验路径

使用 `student1` 登录，点击“试填测量”，整理以下文字：

> 供电 3.30 V，输出 80 mV，黑表笔接 TP0。

核对供电、输出和参考点后确认。输出保留为原始 `80 mV`，换算为 `0.08 V`；规则计算预期 `1.65 V`，显示“输出低于预期”。草稿阶段不会更新测量图表。

退出后用 `teacher` 登录，查看 01 组：原话、确认值、判定、证据时间线应一致。在指导框输入内容并确认发送。再用学生账号登录，学生实验页及过程记录中可看到该指导。

可以继续记录实物修改并复测 `供电3.30 V，输出1.64 V，黑表笔接TP0`，验证曲线跨修订断开，然后提交自己的结论，体验教师退回与反馈。

## 可选模型接入

复制 `.env.example` 为 `.env`，填写提供方的 `LAB_AI_KEY`、`LAB_AI_MODEL`，必要时修改 `LAB_AI_BASE_URL`，重启服务。服务使用 [Chat Completions API 格式](https://developers.openai.com/api/reference/resources/chat)的 `/chat/completions` 接口。密钥只在服务器读取，不下发到浏览器。

模型收到当前权限范围的实验包、当前修订摘要及最近最多 30 条记录。发往模型的结构化记录不附参与者账号 ID、记录人字段和照片文件名。输入的实验文本按数据处理；确定性判定先计算，再提供给模型解释。回答不自动写入测量、消息或成绩，教师必须核对后发送。模型返回的引用及判断仍需人核对。

默认没有配置外部模型，也没有向外部模型发送记录。文字提取目前使用可解释的规则解析，覆盖此实验的常见读数表达；开放式语言理解和照片识别尚未实现。照片仅作为人工可见证据保存。

通义千问的配置和联通测试见[服务器部署说明](deploy/README.md)。模型调用由 `model_client.py` 处理，后续管理端可为该客户端提供已启用的服务商配置。

测试在临时数据库中运行，覆盖草稿确认、师生共享、角色与小组隔离、重试幂等、实物修订、原始单位/负号/OL、判据边界、提交退回与重提、照片权限、模型故障降级。

第一阶段验证结果：26 项后端测试通过；原实验界面与新增管理界面的运行检查通过，覆盖发布前预览、17 个管理弹窗、选组注册、文本转义、输入期间刷新和内网 HTTP 重试。28 项在线教学流程检查通过，临时测试账户、课程与记录已清理。

内置浏览器控制连接连续超时，未完成真实浏览器的点击、截图与手机视觉验收。前端运行检查不等同于浏览器验收。外部模型成功响应仅使用模拟服务验证接口格式，尚未使用真实密钥联调。

## 代码与数据

- `server.py`：API、认证、权限、SQLite 表结构、实验包、提取和规则判定、模型适配。
- `static/`：响应式学生与教师界面，无外部 CDN 依赖；SVG 电压曲线与课堂状态条形图。
- `tests/`：接口与计算语义验收。
- `data/lab.sqlite3`：本机持久化数据库，`data/photos/`：照片文件，均不纳入版本管理。
- `run.py`、`.env.example`：启动和可选模型配置。

首次运行提供一个试用课程、两个小组和分压实验，教师可以继续创建课程、学期、班级、实验内容和任务。数据库版本为 2，启动时自动迁移版本 1 的历史数据；上线前需先备份并用副本演练。SQLite 用于当前单实例试用，正式课堂规模仍需并发和运行验收。

当前报告功能仍是结论提交、退回补充与教师反馈。分章节报告、评分量表和完整课程统计属于第二阶段；千问视觉与视频分析属于后续多模态阶段。

离线文字与失败重试编号以账号分区存于浏览器本地存储；退出不清除暂存，以便重新登录后恢复。测量本身以服务器确认为准。当前未接入仪器、未进行图像识别，也未验证真实教学效果。
