# 验知有道

验知有道——面向实验全过程的多模态智能助教。

以电子电路为首个场景的实验教学助教。学生用自然语言描述测量和观察，核对提取结果后记录；教师通过同一份数据查看实验过程、准备指导与复核结论。后续通过实验包扩展普通物理、化学、生物实验。

当前为教学试用版，包含学生端和教师端，界面采用清爽蓝白设计。

## 功能

- 自然语言提取供电、输出、单位和参考点，确认前不计入测量。
- 保留原话、初始提取、人工修正及单位换算依据。
- 实测与预期电压曲线、课堂进展统计、小组证据时间线。
- 改线或换件创建新实物修订，历史数据保留，当前判定等待复测。
- 学生求助、实验照片、结论提交；教师指导、反馈与退回补充。
- 登录和课程 / 小组权限隔离，写操作重试去重，离线文字暂存。
- 可选模型建议接口；未配置或调用失败时明确显示实验规则建议。

当前文字提取使用实验专用规则；照片作为人工可见证据保存，尚未进行图像识别。模型不自动写入测量、发送指导或生成最终成绩。

## 本地运行

需要 Python 3.9 或更高版本。以下命令在仓库根目录执行：

```sh
python3 -m venv app/.venv
app/.venv/bin/python -m pip install -r app/requirements.txt
app/.venv/bin/python app/run.py
```

打开 <http://127.0.0.1:8765/>。也可在依赖安装后双击 `app/启动助教.command`。

试填：`供电 3.30 V，输出 80 mV，黑表笔接 TP0。` 确认后保留原始 `80 mV`，换算为 `0.08 V`，预期为 `1.65 V`。教师登录后可看到同一记录并发送指导。

## 可选模型

复制 `app/.env.example` 为 `app/.env`，填写 `LAB_AI_KEY`、`LAB_AI_MODEL` 和提供方的 `LAB_AI_BASE_URL` 后重启。密钥仅在后端读取，不进入版本管理。默认不配置外部模型，使用实验规则建议。

## 验证

```sh
cd app
.venv/bin/python -m unittest discover -s tests -v
node --check static/app.js
node tests/check_frontend.cjs
```

后端有 13 项验收测试。前端运行检查覆盖 8 个页面、4 个弹窗、输入期间刷新、文本转义与内网 HTTP 重试兼容。在线部署检查使用独立临时课程，清理自身创建的数据，不覆盖试用记录。

## 目录

```text
app/
  server.py       API、认证、SQLite、实验规则、模型适配
  static/         学生端与教师端响应式界面
  tests/          后端验收与前端运行检查
  deploy/         systemd 配置、在线验收和维护说明
  run.py          启动入口
output/pdf/       多学科建设方案 PDF
output/documents/ 电阻分压实验规格 Word
```

运行时数据库、照片、密钥、虚拟环境和临时生成文件不提交。首次启动时自动创建试用课程、小组及账号。
