# 界面设计基准 v0.2

[approved-ui-v0.2.html](../../app/design/approved-ui-v0.2.html) 保存讨论中确认的第二版交互原型，作为布局、组件和视觉样式的对照基准。原型中的示例班级、小组、时间和测量不能作为线上真实数据。

生产前端使用 `app/static/approved-ui.css` 保留原型组件样式，并通过 `app/static/app.js` 连接现有认证与数据 API。补充样式仅处理登录、真实记录、可访问性和实际设备布局。

对照要点：

- 学生端采用单列实验空间：测量图表在上，实验对话及提取确认在下，底部为实验 / 记录 / 提交导航。
- 普通测量先展示提取结果卡片，数值与单位的编辑收起在“修正识别结果”中。
- 教师端采用窄侧栏、三项行内统计、AI 课堂摘要、进展图表和小组卡片。
- AI 助教页采用居中的任务输入与可编辑草稿；所有指导仍由教师确认发送。
- 登录页沿用同一套蓝白组件，进入后按服务器授权显示相应角色。

第一阶段新增课程入口使用同一套组件：教师顶部提供学期课程、实验任务和教学班切换；侧栏分为教学资源与当前课程。学生从课程、任务和选组页面进入原实验空间，实验内仍保留三项底部导航。发布操作先展示摘要，再确认执行。

前端运行检查覆盖这些结构和真实数据边界。实际浏览器视觉验收仍需完成，不能以结构测试替代截图对照。
