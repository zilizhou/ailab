# 验知有道功能规格 v0.2

项目全称：验知有道——面向实验全过程的多模态智能助教。

本版需求面向教师同时承担多门课程、跨学期组织实验的实际教学场景，覆盖实验内容管理、班级与分组、任务发布、实验过程、报告批改和统计分析。首个实验继续使用电阻分压，管理端后续建设。

本规格描述分阶段建设目标。第一阶段已实现多课程、多学期、实验讲义、班级管理、学生自主分组及实验任务发布；第二阶段的完整报告评价与课程统计，以及第三阶段多模态能力继续按下文推进。已确认的界面设计基准见 [界面设计说明](../design/README.md)。

## 课程与实验的组织方式

课程长期保留，每个学期创建对应的开课记录。教师可参与多门开课课程，同一门课程也可由多位获授权教师共同承担。学生账号可以加入不同课程的教学班。

| 对象 | 含义 | 主要关系 |
| --- | --- | --- |
| 学期 | 例如 2026至2027学年第一学期 | 用于组织开课课程和筛选历史数据 |
| 课程 | 电子电路基础、普通物理实验等长期课程 | 同一课程可在多个学期开设 |
| 开课记录 | 某课程在某学期的教学安排 | 关联任课教师和教学班 |
| 教学班 | 该次开课的学生名单和教学单元 | 可包含一个行政班，也可合班教学 |
| 实验讲义 | 可复用的实验目标、步骤、判据、报告要求和 PDF 或 Word 原文件 | 可用于不同课程或不同学期 |
| 实验任务 | 讲义向指定教学班的一次发布 | 保存开放时间、截止时间、分组及评价设置 |
| 分组方案与小组 | 固定分组或针对某次任务建立的分组 | 学生在同一分组方案中只能属于一个小组 |
| 小组实验 | 某小组针对某次发布开展的实验 | 独立保存实物修订、记录、求助、报告与反馈 |

实验模板与实验任务分开管理。例如，同一份电阻分压模板可用于本学期两个教学班；下学期再次发布时创建新的任务，历史记录仍属于原来的任务。

复制往期开课时，教师选择复用的实验模板和任务配置，并重新设置日期、班级及学生名单。往期测量、提交和成绩保留在原学期。讲义直接更新，已发布任务显示当前正文及附件，并保留原判定方式和参数。

## 教师功能

| 功能 | 教师可以执行的操作 | 保存或展示的结果 |
| --- | --- | --- |
| 课程与学期管理 | 新建课程、开设学期课程、切换学期、复制开课结构、归档 | 各学期独立的课程列表和教学历史 |
| 实验内容管理 | 创建、编辑、复制实验；管理材料、步骤、测量量、单位、异常案例、判据和报告模板 | 可复用、可直接编辑或上传原文件的讲义 |
| 班级管理 | 创建教学班、导入或添加学生、邀请学生加入、维护名单 | 课程下的班级与选课学生关系 |
| 分组管理 | 配置人数、创建或调整分组、开放学生选组、自动分配、锁定名单 | 明确的小组与成员关系 |
| 发布实验 | 选择讲义、目标班级、开放与截止时间、分组及报告模式 | 可预览、发布和跟踪的实验任务 |
| 过程监控 | 查看阶段、已确认测量、异常提示、求助、修改复测及同步时间 | 班级总览和每组证据时间线 |
| 报告批改 | 按量表查看报告与原始证据、评分、反馈、退回、复核重提 | 关联报告版本的教师评价 |
| 数据分析 | 按学期、课程、班级、实验和小组筛选、比较和导出 | 图表及带统计口径的汇总结果 |
| AI 教学辅助 | 准备实验内容、起草任务、整理求助、起草指导和批改反馈、形成教学小结 | 可编辑且附依据的草稿 |

教师默认管理自己的课程和实验资源；共享资源须有明确授权。课程协作教师按授课关系获得权限，学生仅能访问自己所在教学班和获授权的小组内容。

AI 生成的实验内容由教师审核后使用。AI 起草发布任务时，先展示课程、学期、班级、讲义、时间和人数等提取结果，教师核对后发布。指导、报告评分和反馈均保留教师确认环节。

## 学生分组与协作

“学生自动选择分组”先按学生自主选组设计，同时预留教师启用系统分配的方式。教师为每次任务选择沿用教学班固定分组，或重新建立任务分组。

| 分组方式 | 学生操作 | 教师设置 |
| --- | --- | --- |
| 单人实验 | 选择独立完成，创建人数为一的小组 | 是否开放单人模式 |
| 自主组队 | 创建小组或加入尚有名额的小组 | 最少和最多人数、是否允许学生建组、选组截止时间 |
| 系统分配 | 查看系统分配结果 | 在本教学班符合条件的学生中分配，避免重复入组和超员 |
| 教师指定 | 查看教师安排的组别 | 手动建立或调整成员 |

同一任务可允许单人组与多人组并存，例如设置人数范围为一至四人。学生在不同课程、不同任务中可以采用不同组队方式。跨班组队须由教师显式开放。

选组阶段允许按教师规则调整。默认在首次正式记录实验前确认并锁定成员名单；教师后续调整成员时保存变更记录。已有记录保留原作者和当时的成员信息，报告保留提交时的成员名单。

多人小组共享同一个实验空间。每条测量、观察、照片、视频和修改记录均保存提交者与时间；多人同时记录时，系统处理重复请求和版本冲突，避免覆盖同伴记录。

## 实验发布与学生实验流程

教师先建立学期开课记录和教学班，准备实验模板，再为目标班级发布任务。一次发布可覆盖多个教学班，各班分别采用自己的分组方案。

发布配置包括实验讲义、目标班级、开放与截止时间、选组规则、报告模式和评价量表。内容引用和评价设置随任务保存。调整时间等已发布设置时生成变更记录，并向受影响学生展示；需要改变判据时另建讲义并发布新任务，原记录继续用原判据解释。截止时间到达后，原始实验记录仍保留。

学生从“我的课程”进入某学期课程，查看实验任务，完成选组并打开实验。实验空间继续采用“实验、记录、我的”三个入口，结论与提交放在具体实验内。

1. 学生查看实验目标、材料、步骤和注意事项，先记录预测或初步解释。
2. 学生用自然语言输入读数、检查发现或问题，也可上传图片；视频分析在多模态阶段接入。
3. 平台展示提取草稿，保留原话与证据来源。涉及数值和实验事实的草稿由学生核对后记入。
4. 程序按实验包计算和判定，AI 根据已确认记录提出检查建议，并标明待核对项。
5. 改线、换件或改变实验条件后建立新的实物修订，再测量验证；历史记录继续可查。
6. 学生说明结论与证据的关系，完成报告并提交；收到退回意见后补充并重新提交。

AI 识别应区分原理图标称值、仪表实测值和推测信息。图片位置、视频时间戳、原始单位与人工修正关联保存。无法识别、未测量和离线未同步均分别标记，不作为数值零进入统计。

## 过程监控

课堂总览按实验任务和教学班显示已分组、待开始、进行中、主动求助、已提交、待补充及已反馈情况。教师可以进入任一获授权小组，查看测量变化、检查与修改记录、对话和报告。

过程监控首先依据已同步的实验记录、任务状态和求助。同步较久没有更新时显示最后同步时间。图像与视频分析可补充过程证据；未观察到某一步骤时标记待核对，教师结合其他证据判断。

## 实验报告与评价

报告模式在发布时确定：小组共同提交一份报告、每位学生独立提交，或小组报告配个人反思。小组模式保存每位成员的操作记录，教师可据此了解参与情况，不能仅以输入次数判断学习贡献。

个人报告及个人反思默认仅本人和任课教师可见；小组共同报告对该次实验的获授权成员开放。

报告模板可包含实验目的、原理与预测、方法、数据与图表、异常与排查、结论和反思。实验记录可以自动关联或整理到报告中，学生负责核对和撰写解释。

提交生成独立报告版本，并固定引用实验任务、过程证据和成员名单。退回后生成新版本，原提交与教师意见仍可追溯。教师按量表给出分项评价、反馈和最终分数；AI 提供附证据的批改草稿，教师确认后发布。

量表可分别评价操作过程、数据质量、分析解释和报告表达。成绩以小组或个人为单位的计算方式随任务保存；修改已发布评分时记录修改人、原因和时间。

## 数据展示与统计

| 范围 | 主要展示 | 适合的图表 |
| --- | --- | --- |
| 单个小组 | 读数与预期、偏差、实物修订、复测变化、过程证据 | 折线、散点、带参考区间的曲线、时间线 |
| 一次实验任务 | 参与与提交情况、小组对比、偏差分布、求助及反馈情况 | 条形、趋势、分布图 |
| 一个教学班 | 不同实验的完成情况、评价结果、共性问题 | 实验进度图、矩阵、分项比较 |
| 一门学期开课 | 班级对比、实验项目分布、报告评价汇总 | 汇总趋势、班级比较、分项分布 |

图表显示筛选范围、统计单位、分母、样本量和更新时间。按组统计与按学生统计分别标注，单人组和多人组均按所选口径计算。未选组学生单独展示。

测量对比限定在相同判据、测量量、单位和可比条件下。默认比较每组当前修订的最新有效确认值，并提供查看全部历史测量的入口，避免测量次数多的小组在汇总中被重复加权。

数值符合判据、完成提交和达到学习目标分别展示。自动生成的异常分类保留依据与待核对状态。教师可查看班级汇总，学生默认查看本组数据；公开其他组示例须由教师选择展示范围。

## 界面入口

教师保留已确认的蓝白风格和窄侧栏，在顶部增加学期和课程切换。功能按“我的课程与实验资源”和“当前课程教学”组织，当前课程包含教学总览、班级分组、实验任务、报告批改、数据分析与 AI 助教。

学生增加课程、任务和选组入口。进入具体实验后，继续使用已确认的单列图表与实验对话布局，以及底部“实验、记录、我的”导航，结论与提交从实验内进入。新增能力以任务和对话为入口，常规记录优先展示提取卡片，手动修正收在详情中。

## 数据与权限改造

当前账号直接关联一个课程和一个小组，下一版改为通过授课、选课、班级成员和小组成员关系确定访问范围。小组实验承接原来保存在小组上的修订和提交状态，防止同组开展不同实验时互相覆盖。

实验记录、媒体、AI 指导、报告及教师反馈统一关联小组实验；个人报告额外关联提交学生。每次读取、写入和 AI 上下文组装均校验课程、教学班、实验任务及成员权限。

迁移时为现有试用课程建立学期开课记录、教学班、分组方案和实验任务，再将原小组记录关联到相应小组实验。保留原作者、时间、原始单位、证据引用与修订关系。备份后验证数据数量和权限，再切换新版本。

## 开发顺序与验收

| 阶段 | 交付范围 | 主要验收场景 |
| --- | --- | --- |
| 第一阶段 | 多课程、多学期、实验内容库与版本、教学班、名单、分组、任务发布及权限 | 一名教师同时管理两门课程；同课程跨学期独立；学生可独立完成或加入多人组；只看到获授权任务 |
| 第二阶段 | 多组实验空间、过程监控、报告模板、评分与退回、统计图表 | 不同任务中的修订互不影响；多人记录保留作者；报告重提有版本；图表口径可解释 |
| 第三阶段 | 千问文字指导、图片证据分析、短视频复盘与教师批改草稿 | 识别结果先核对，指导可追溯证据，模型故障不影响实验记录 |

下一次开发先完成第一阶段，贯通“教师开课建班并发布实验—学生选组—各组进入各自实验—教师查看进展”。教师端和学生端新增入口先补充到现有设计稿，再实现和验收。

验收至少覆盖以下情况：

- 同一教师跨课程、跨学期切换时，名单、实验记录和成绩不会混入其他课程。
- 实验模板升级后，已发布任务仍可读取原版本内容与判据。
- 两名学生同时加入最后一个空位时，仅允许符合人数限制的请求成功。
- 学生创建单人组后不能同时加入同任务另一组；不同课程可以加入不同组。
- 同一分组方案可服务多个实验任务，各任务的实物修订、记录和报告独立。
- 开始实验后教师调整成员，已有记录和报告仍能追溯当时的作者及成员。
- 多人小组重复发送、同时记录或离线恢复时，不产生重复测量或覆盖他人记录。
- 教师退回报告后学生可补充重提，原提交、反馈和分数变更历史可查。
- 学生通过直接请求接口、媒体地址或 AI 提问，均不能越权读取其他班级或小组材料。
- 汇总图表正确处理单人组、多人组、未选组、未测量和未同步数据，并显示样本量与分母。
- AI 起草的发布、指导和评分不会在教师确认前作为正式操作执行。
